# Spinner

> Spinner component.

> **[View rendered page](https://design.sunbeam.pt/components/spinner?render=html)** — see the live component with full DOM structure and styling.

## Import
```tsx
import { Spinner } from "@sunbeam/beam-ui/components/ui/spinner"
```

## Props
| Prop | Type | Required | Description |
|------|------|----------|-------------|
| size | `"sm" | "md" | "lg"` | No | Size of the spinner |
| label | `string` | No | Optional label shown below the spinner |
| accent | `boolean` | No | Use brand color instead of muted |
| color | `string` | No | Custom color for the spinner arc (overrides accent) |
| className | `string` | No |  |
