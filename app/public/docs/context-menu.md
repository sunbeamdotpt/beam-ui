# ContextMenu

> ContextMenu component.

> **[View rendered page](https://design.sunbeam.pt/components/context-menu?render=html)** — see the live component with full DOM structure and styling.

## Import
```tsx
import { ContextMenu } from "@sunbeam/beam-ui/components/ui/context-menu"
```

## Props
| Prop | Type | Required | Description |
|------|------|----------|-------------|
| items | `ContextMenuItem[]` | Yes | Array of menu items to display. |
| children | `ReactNode` | Yes | Element or component that triggers the context menu on right-click. |
