# DropdownMenu

> DropdownMenu component.

> **[View rendered page](https://design.sunbeam.pt/components/dropdown-menu?render=html)** — see the live component with full DOM structure and styling.

## Import
```tsx
import { DropdownMenu } from "@sunbeam/beam-ui/components/ui/dropdown-menu"
```

## Props
| Prop | Type | Required | Description |
|------|------|----------|-------------|
| items | `DropdownMenuItem[]` | No | Flat list of items (mutually exclusive with `groups`). |
| groups | `DropdownMenuGroup[]` | No | Grouped list of items (mutually exclusive with `items`). |
| children | `ReactNode` | Yes | Element or component that triggers the dropdown on click. |
