# FeatureTile

> FeatureTile component.

> **[View rendered page](https://design.sunbeam.pt/components/feature-tile?render=html)** — see the live component with full DOM structure and styling.

## Import
```tsx
import { FeatureTile } from "@sunbeam/beam-ui/components/ui/feature-tile"
```

## Props
| Prop | Type | Required | Description |
|------|------|----------|-------------|
| name | `string` | Yes | Display name of the feature (e.g., "Analytics", "File Upload"). |
| endpoint | `string` | Yes | URL endpoint or path for this feature. |
| icon | `string` | Yes | Material Design icon name to display above the name. |
