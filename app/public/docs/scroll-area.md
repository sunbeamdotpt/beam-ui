## Import
```tsx
import { ScrollArea } from "@sunbeam/beam-ui/components/ui/scroll-area"
```

## Props
| Prop | Type | Required | Description |
|------|------|----------|-------------|
| children | `ReactNode` | Yes |  |
| maxHeight | `string` | No |  |
| scrollbar | `"visible" | "hover" | "auto"` | No | "visible" always shows themed scrollbar, "hover" hides until hover, "auto" uses browser default with theme colors |
| direction | `"vertical" | "horizontal" | "both"` | No | Scroll direction |
| className | `string` | No |  |
